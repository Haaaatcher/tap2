# **TAP2** *v0.1.0*

## 一、用户指南

### 1.1 安装与启动

安装 `tap2` 需要确保 `python>=3.10`，建议在新的虚拟环境中安装（例如使用 [Anaconda](https://www.anaconda.com/) 包管理工具），避免出现软件包的版本冲突。

```bash
# conda create -n tap2 python=3.10
# conda activate tap2
pip install ./tap2-0.1.0-py3-none-any.whl
```

在本地开启 `tap2` 的用户界面需在终端中启动 `tapu`（含义是：`TAP2's UI`）命令，输出如下信息则表示开启成功，在浏览器中进入[输出的 URL](http://127.0.0.1:7860) 使用 `tap2` 。使用 `Ctrl+C` 关闭 `tap2`。

如需供给外部访问，使用 `tapu` 命令的 `--host` 和 `--port` 参数分别指定 IPv4 地址和端口号（默认为`7860`），例如：

```bash
tapu --host 127.0.0.1 --port 8000
```

### 2.3 API 使用

`tap2` 支持使用 `Python SDK` 和 `OpenAPI` 进行钛合金性能预测，均支持**单点预测**和**批量预测**两种方式。

#### 2.3.1 Python SDK

在 Python 脚本中导入相关类：`TAPPInput`、`TAPPBatchInput` 和 `TAPPInfer`，下面是示例代码：

- **单点预测**

```python
from tap2 import TAInput, TAInfer

# 创建 TAPP 推理器实例
ta_infer = TAInfer()

# 用字典定义单条输入数据
data = {"prop": "DS", "Ti": 90.0, "H": 0.0, "B": 0.0, "C": 0.0, "N": 0.0, "O": 0.0, "Al": 6.0, "Si": 0.0, "Cr": 0.0,
        "Fe": 0.0, "Ni": 0.0, "Cu": 0.0, "Zr": 0.0, "Nb": 0.0, "Mo": 0.0, "V": 4.0, "Sn": 0.0, "HTT": 800.0}

# 创建 TAPP 单一输入实例
data = TAInput(**data)

# 调用 TAPP 进行推理
result = ta_infer(data).value

# 打印浮点数结果
print(f"Density: {result :.3f} g/cm^3")

# Density: 4.457 g/cm^3
```

- **批量预测**

```python
from tap2 import TABatchInput, TAInfer

# 创建 TAPP 推理器实例
ta_infer = TAInfer()

# 用字典定义多条输入数据，其中字典的值为列表
data = {
  "prop": "DS",
  "Ti": [90.0, 97.0],
  "H": [0.0, 0.0],
  "B": [0.0, 0.0],
  "C": [0.0, 0.0],
  "N": [0.0, 0.0],
  "O": [0.0, 0.0],
  "Al": [6.0, 3.0],
  "Si": [0.0, 0.0],
  "Cr": [0.0, 0.0],
  "Fe": [0.0, 0.0],
  "Ni": [0.0, 0.0],
  "Cu": [0.0, 0.0],
  "Zr": [0.0, 0.0],
  "Nb": [0.0, 0.0],
  "Mo": [0.0, 0.0],
  "V": [4.0, 0.0],
  "Sn": [0.0, 0.0],
  "HTT": [800.0, 800.0]
}

# 创建 TAPP 批量输入实例
data = TABatchInput(**data)

# 调用 TAPP 进行推理
results = ta_infer(data).value

# 打印浮点数结果
for result in results:
  print(f"Density: {result :.3f} g/cm^3")

# Density: 4.457 g/cm^3
# Density: 4.460 g/cm^3
```

- **注意事项**

  - 输入数据中元素组成之和必须为 `100`。
  - 当预测力学性能（`屈服强度`、`抗拉强度`、`硬度`、`霍尔佩奇系数`）时，还需要在输入数据中提供晶粒尺寸（`GS`），单位为微米。
  - 批量计算以最小列表长度为准。
  - 计算结果除相比例为 `TAPPPhaseRatio` 类型外，其余均为浮点数类型。
  - 性能字段（`Prop`）的取值、含义及单位如下：

    - `WF`: 相比例（$wt\%$)
    - `TE`：热膨胀系数（$K^{-1}$）
    - `DS`：密度（$g/cm^3$）
    - `TC`：热导率（$W/m·K$）
    - `EC`：电导率（$S/m$）
    - `YM`：杨氏模量（$GPa$）
    - `BM`：体积模量（$GPa$）
    - `SM`：剪切模量（$GPa$）
    - `PR`：泊松比
    - `SE`：比焓（$J/g$）
    - `SHC`：比热容（$J/g·K$）
    - `YS`：屈服强度（$MPa$）
    - `TS`：抗拉强度（$MPa$）
    - `HD`：硬度（$VPN$）
    - `HP`：霍尔佩奇系数（$MPa·m^{\frac{1}{2}}$）
  - `HTT` 表示热处理温度，单位为摄氏度。

## 二、性能预测算法

`tap2` 的性能预测使用了基于 `MoE` 的机器学习算法：建立若干个**元素专家**和一个**专家评分器**，元素专家接收 Ti 元素和对应元素的浓度作为输入，并输出预测的性能值，专家评分器则接收全部元素组成作为输入，输出对各个元素专家的评分，最后将各个元素专家给出的性能值和评分器给出的专家评分进行加权求和，得到最终的性能值。

该算法的好处是能够从元素角度捕捉数据的宏观和微观特征，元素专家能够计算出每种元素对于特定性能的贡献，而专家评分器能够平衡各元素的贡献程度。

## 三、性能修正算法

### 3.1 强度修正算法

强度修正分为两个步骤：

1. 微量元素（`N`, `O`, `C`, `H`, `B`）修正：将微量元素的浓度和其对应系数相乘并求和，其中抗拉强度的增量为屈服强度增量的 **1.1** 倍。

   $$
   \Delta_{YS} = Wt(N) \times 2185.6 + Wt(O) \times 1219.86 + Wt(C) \times 704.2 + Wt(H) \times 268.0 - Wt(B) \times 34.0 \\
   $$

   $$
   \Delta_{TS} = 1.1 \times \Delta_{YS}
   $$
2. 晶粒尺寸修正：机器学习模型计算的是晶粒尺寸为10微米的强度性能，利用霍尔-佩奇公式可得任意晶粒尺寸下的强度性能：

   $$
   \Delta_{GS} = k_{HP} \times ( d^{- \frac{1}{2}} - d_0^{- \frac{1}{2}} )
   $$

### 3.2 物理性能修正算法

物理性能修正的增量是将每种主要元素（`Al`, `Cr`, `Cu`, `Fe`, `Mo`, `Nb`, `Ni`, `Si`, `Sn`）和微量元素（`C`, `N`, `O`, `B`, `H`）的组合与其对应系数相乘并求和：

$$
\Delta_{prop} = \sum_{e1, e2} Wt(e_1) \times Wt(e_2) \times k_{prop}(e_1, e_2)
$$

### 3.3 热膨胀系数修正算法

热膨胀系数修正通过给原始热膨胀系数加一个微量元素（`H`、`B`、`C`、`N`、`O`）的影响增量实现，增量计算公式如下：

$$
\Delta = \Delta_H + \Delta_B + \Delta_C + \Delta_N + \Delta_O
$$

$$
\Delta_H = - 5.93 \times 10^{-6} \times Wt^{3}_H + 1.74 \times 10^{-6} \times Wt^{2}_H - 5.52 \times 10^{-7} \times Wt_H + 4.56 \times 10^{-9}
$$

$$
\Delta_B = - 1.949381 \times 10^{-7} \times Wt^{3}_B - 8.598354 \times 10^{-8} \times Wt^{2}_B - 4.072913 \times 10^{-8} \times Wt_B + 3.085894 \times 10^{-10}
$$

$$
\Delta_C = 2.52 \times 10^{-7} \times Wt^{3}_C + 1.22 \times 10^{-7} \times Wt^{2}_C - 1.22 \times 10^{-7} \times Wt_C - 7.23 \times 10^{-10}
$$

$$
\Delta_N = - 1.37 \times 10^{-6} \times Wt^{3}_N + 8.76 \times 10^{-7} \times Wt^{2}_N - 4.6 \times 10^{-7} \times Wt_N - 2.89 \times 10^{-10}
$$

$$
\Delta_O = - 1.089075 \times 10^{-6} \times Wt^{3}_O - 3.124228 \times 10^{-9} \times Wt^{2}_O + 8.039267 \times 10^{-7} \times Wt_O - 4.282498 \times 10^{-10}
$$
